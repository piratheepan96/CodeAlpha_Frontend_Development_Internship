# Task 1 - Image Gallery

## CodeAlpha Frontend Development Internship

This project is an interactive and responsive Image Gallery developed as part of the CodeAlpha Frontend Development Internship.

## Project Overview

The Image Gallery allows users to view a collection of images in a clean and responsive layout. Users can open images in a lightbox, navigate between images, close the lightbox, and filter images by category.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub

## Features

- Responsive image gallery
- Multiple image categories
- Category filtering
- Image lightbox
- Next and Previous image navigation
- Close lightbox button
- Keyboard navigation
- Escape key support
- Responsive design for different screen sizes
- Clean and user-friendly interface
